# Contributing

Changes are welcome through issues and pull requests. Use Node.js 22+ and run `npm test`; on Windows also run `npm run build` and `npm run package`. No npm dependencies are required.

Include the Windows, Codex and Node.js versions when reporting compatibility problems. Replace chat IDs, file paths and message contents with fictional values. Do not attach `.codex` folders, session logs, `auth.json`, runtime settings or account credentials.

For accounting changes, include synthetic tests for unknown models, duplicate requests, cache/input overlap and missing usage. Explain the public pricing source and effective date. For navigation changes, cover chat switching, cloud routes and ambiguous windows. Keep pricing estimates separate from subscription allowance claims.

The native strip is C# compatible with the Windows .NET Framework compiler. Keep the backend dependency-free unless a change has a clear reason to add a package. Contributions are distributed under the repository's MIT License.
